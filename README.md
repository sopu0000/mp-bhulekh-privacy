# MP Bhulekh – Land Records: Privacy Policy

This repository hosts the privacy policy for the **MP Bhulekh – Land Records** Android app
(`com.mpbhulekh.app`).

Live page: https://sopu0000.github.io/mp-bhulekh-privacy/

This is an independent app. It is **not** made by, endorsed by or connected to the
Government of Madhya Pradesh. Land records shown in the app come from the public
MP Bhulekh portal, https://mpbhulekh.gov.in.
